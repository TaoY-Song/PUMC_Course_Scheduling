欢迎安装PUMC智能排课系统！

=== 安装前重要提示 ===

系统要求：
- 操作系统：Windows 10 或更高版本（64位）
- 内存：至少 4GB RAM（推荐 8GB 或更多）
- 磁盘空间：至少 2GB 可用空间
- 处理器：Intel i3 或同等性能的 AMD 处理器

安装前准备：
1. 请确保您具有管理员权限
2. 建议临时关闭杀毒软件以避免误报
3. 关闭所有正在运行的应用程序
4. 确保网络连接正常（用于验证和更新）

安装路径说明：
- 默认安装路径：C:\Program Files\PUMC智能排课系统
- 您可以在后续步骤中自定义安装路径
- 请确保安装路径有足够的磁盘空间

重要提醒：
- 安装过程中请勿关闭安装程序
- 如遇到问题，请联系技术支持
- 安装完成后将在桌面创建快捷方式

接下来您将看到免责声明和使用协议，
请仔细阅读并确认同意后方可继续安装。

点击"下一步"继续安装向导。
