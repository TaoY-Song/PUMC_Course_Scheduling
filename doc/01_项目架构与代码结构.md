# PUMC智能排课系统 - 项目架构与代码结构

## 📋 概述

本文档基于实际代码分析，详细描述PUMC智能排课系统的真实架构实现。系统采用四层架构设计，使用PyQt5作为GUI框架，使用纯 Python 回溯搜索作为唯一排课求解器。

#### 4. 排课算法模块 (core/scheduling/)

**SchedulingConfig类 (config.py)：**
```python
@dataclass
class SchedulingConfig:
    # 校区冲突配置
    campus_conflict_mode: CampusConflictMode = CampusConflictMode.DAILY
    min_campus_transfer_time: int = 2
    
    # 学分约束配置  
    credit_constraint_mode: CreditConstraintMode = CreditConstraintMode.OPTIMAL
    allow_credit_overflow: bool = True
    max_credit_overflow_ratio: float = 0.2
    credit_gap_weight: float = 0.1
    
    # 求解器配置
    max_solve_time_seconds: int = 30
    max_solutions: int = 100
    
    def to_dict(self) -> Dict
    @classmethod
    def from_dict(cls, data: Dict) -> 'SchedulingConfig'
```

**枚举类型：**
```python
class CampusConflictMode(Enum):
    DISABLED = "disabled"    # 禁用校区冲突检查
    DAILY = "daily"         # 按天检查校区冲突
    PERIOD = "period"       # 按时段检查校区冲突

class CreditConstraintMode(Enum):
    REQUIRED = "required"    # 必需模式：严格满足学分要求
    OPTIMAL = "optimal"     # 优化模式：尽量满足学分要求
```
