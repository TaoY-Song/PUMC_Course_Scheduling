## 🔧 故障排除

### 1. OR-Tools依赖问题（重要）

**错误：OR-Tools未安装或ImportError**
```
ImportError: OR-Tools未安装，无法使用排课功能。
```

**解决方案**：
```bash
# 方法1：使用专用脚本（推荐）
PUMC_venv/Scripts/python.exe build_with_ortools.py

# 方法2：手动添加OR-Tools
PUMC_venv/Scripts/python.exe -m PyInstaller --collect-all=ortools --hidden-import="ortools.sat.python.cp_model" app.py

# 方法3：验证虚拟环境中的OR-Tools
PUMC_venv/Scripts/python.exe -c "import ortools; print('OR-Tools path:', ortools.__file__)"
```

**原因分析**：
- OR-Tools包含大量C++二进制文件(.pyd, .dll)
- PyInstaller无法自动检测所有OR-Tools依赖
- 必须使用`--collect-all=ortools`参数或手动复制

### 2. 常见打包错误

**错误：ModuleNotFoundError**
```bash
# 解决方案：使用虚拟环境添加隐藏导入
PUMC_venv/Scripts/python.exe -m PyInstaller --hidden-import=缺失模块名 app.py
```

**错误：DLL加载失败**
```bash
# 解决方案：在虚拟环境中检查依赖
PUMC_venv/Scripts/python.exe -c "import 模块名"
# 重新安装相关包
PUMC_venv/Scripts/pip.exe uninstall 包名
PUMC_venv/Scripts/pip.exe install 包名
```

**错误：文件路径过长**
