# PUMC 智能排课系统 v3.0

基于 Web 的研究生课程智能排课工具。导入课程一览表后，系统自动分析时间冲突、学分缺口与校区约束，生成满足培养方案要求的排课方案。

---

## 环境要求

| 依赖 | 版本 |
|------|------|
| Python | 3.11+ |
| Node.js | 18+ |
| 操作系统 | Windows（推荐 PowerShell） |

## 安装

**第一步：Python 依赖**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

**第二步：前端依赖**

```powershell
cd web
npm ci
cd ..
```

**第三步：构建前端**

```powershell
cd web
npm run build
cd ..
```

## 启动

```powershell
python app_web.py
```

打开浏览器访问：`http://127.0.0.1:8000`

接口文档：`http://127.0.0.1:8000/docs`

## 使用流程

### 第一步：导入课程表

进入「课程工作台」页面，点击**导入课程表**，选择学校提供的课程一览表 Excel 文件（`.xls` 或 `.xlsx`）。

导入成功后页面显示课程列表和课程总数。

---

### 第二步：整理已选课程

在课程目录里搜索并点击**加入**，把本学期需要排课的课程加入右侧已选列表。

对每门已选课程：

- **设置类别**：下拉选择对应培养方案类别（公共必修、核心课、学位选修等）。类别未设置的课程不计入学分、排课时被忽略。
- **设置时间段**：点击「新增」，在弹窗里选择星期、节次，然后按住拖动连选上课周次，点「保存时间段」。
- **例外周**：某几周改到不同时间时，再次点「新增」→ 勾选「这几周改到别的时间上」，选替代哪个常规时间段，勾选例外周次保存，系统自动从常规段扣除这几周。

---

### 第三步：设置学分要求

进入「学分设置」页面，按本学期的培养方案缺口填写各类别目标学分，点击**保存设置**。

> 这里填的是**本学期还差多少分**，不是整个学位的总量。填得过高时优化模式会放弃无法改善缺口的课程。

---

### 第四步：执行排课

进入「智能排课」页面：

1. 选择约束模式：
   - **OPTIMAL**：最优化模式，尽量多排、贴近学分目标
   - **REQUIRED**：严格模式，无法满足要求时直接失败
2. 选择校区冲突策略（PERIOD 模式按半天时段块检查跨校区）
3. 调整溢出学分上限、时间限制等参数（可选）
4. 点击**开始排课**

任务异步执行，页面实时显示进度日志，完成后自动展示排课结果和周课表。

---

### 第五步：导出结果

排课完成后点击**导出 Excel**，下载包含逐条课程明细的结果文件。

---

### 第六步：补充测试（可选）

进入「补充测试」页面：

1. 上传刚才导出的**排课结果 Excel**（必选）
2. 如需使用其他课程源，上传**原始课程一览表**（可选，不上传则用当前会话已导入的课程表）
3. 点击**开始补充测试**

系统会把尚未排入的课程见缝插针补入空档，生成更完整的课表供参考，下载结果 Excel 即可。

## 项目结构

```
PUMC_Course_Scheduling/
├── app_web.py              # 启动入口
├── core/                   # 排课核心逻辑
│   ├── scheduling/         # 约束求解器、配置、评分
│   ├── services/           # 数据服务、任务管理、事件总线
│   └── data_loader.py      # Excel 解析
├── web_backend/            # FastAPI 后端
│   ├── api/                # REST + WebSocket 路由
│   ├── models/             # DTO / 请求响应模型
│   └── server.py           # 应用实例
├── web/                    # React 前端
│   └── src/
│       ├── pages/          # 各功能页面
│       ├── components/     # 共用组件
│       └── lib/            # API 客户端、工具函数
├── scripts/                # E2E 验收脚本
├── tests/                  # Python 单元/集成测试
└── test_data/              # 测试用课程表源文件
```
