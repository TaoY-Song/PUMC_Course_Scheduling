# PUMC智能排课系统

## 📋 项目简介

基于PyQt5的智能排课系统，采用现代化四层架构设计，集成OR-Tools约束求解器，支持Excel数据加载、可视化算法配置、智能排课算法、结果展示和高级导出功能。系统实现了完整的学分管理、时间冲突检测、校区冲突处理和课程补充测试等功能。

## 🚀 快速开始

### 环境要求

- Python 3.7+
- PyQt5 5.15.10
- pandas 2.0.3
- openpyxl 3.1.2 (用于读取Excel文件)
- OR-Tools 9.7.2996 (约束求解器)

### 安装依赖

```bash
# 安装所有依赖
pip install -r requirements.txt

# 或者手动安装核心依赖
pip install PyQt5==5.15.10 pandas==2.0.3 openpyxl==3.1.2 ortools==9.7.2996
```

### 运行应用

```bash
python app.py
```

## 📖 使用说明

### 1. 数据加载

1. 点击左侧面板的"选择Excel文件"按钮
2. 选择课程一览表Excel文件（支持.xlsx和.xls格式）
3. 系统自动加载并显示加载状态和课程数量

### 2. 课程管理

1. 在"课程编码"输入框中输入课程编码（如：BIEN01002）
2. 点击"查找课程"按钮查看课程详细信息
3. 从下拉框中选择具体班次
4. 系统自动识别线上课程状态（基于Excel"是否线上"列）
5. 点击"添加课程"将课程添加到已选列表

### 3. 时间安排配置

1. 在右侧"课程管理与结果展示"区域选择一门课程
2. 点击"添加时间段"按钮打开时间配置对话框
3. 配置时间信息：
   - **星期几**：选择上课的星期（周一到周日）
   - **节次**：设置开始和结束节次（1-12节）
   - **周次**：点击18个方块选择上课周次（1-18周）
   - 使用"全选"/"清空"按钮快速操作
4. 点击"添加时间段"确认配置

### 4. 智能排课

1. 在右侧"算法配置"区域设置排课参数：
   - **学分约束模式**：必需模式/优化模式
   - **校区冲突模式**：禁用/按天检查/按时段检查
   - **其他参数**：学分溢出比例、跨校区间隔时间等
2. 点击"执行控制"区域的"开始智能排课"按钮
3. 系统显示排课进度和状态信息
4. 排课完成后在"结果展示"区域查看结果

### 5. 学分管理

- **学分统计**：左侧面板实时显示各类别学分完成情况
- **学分设置**：点击"学分设置"按钮配置各类别的学分要求
- **自动分类**：系统根据课程类别自动设置学分类别
- **手动调整**：可手动修改课程的学分类别

### 6. 导入导出功能

- **导出已选课程**：点击"导出已选课程"按钮保存当前选择
- **导入课程**：点击"导入课程"按钮从Excel文件恢复课程选择
- **导出排课结果**：排课完成后点击"导出排课结果"按钮
- **Excel格式**：支持完整的课程信息和时间安排数据

## 🔧 技术特点

### 架构设计

- **四层架构**：应用入口层 → 用户界面层 → 服务接口层 → 核心业务层
- **模块化设计**：每个功能模块独立，职责清晰，便于维护
- **接口抽象**：ISchedulingService、IDataService等抽象接口定义
- **依赖注入**：ServiceFactory工厂模式管理服务实例
- **事件驱动**：EventManager实现观察者模式，组件间松耦合通信

### 核心技术

- **OR-Tools集成**：Google OR-Tools 9.7.2996约束求解器
- **PyQt5界面**：专业的桌面应用界面框架
- **pandas数据处理**：高效的Excel数据读取和处理
- **多线程处理**：CourseLoadThread避免界面冻结
- **线程安全**：服务层使用Lock确保并发安全

### 算法优化

- **三阶段排课**：线上课程 → 约束满足 → 结果合并
- **智能预筛选**：大规模课程数据的自动筛选优化
- **回溯算法**：完整的约束满足问题求解
- **贪心策略**：线上课程和简化场景的高效处理
- **评分机制**：基于学分匹配度和时间质量的综合评分

## 📊 数据格式要求

### 课程一览表Excel格式

**必需列**：
- 课程编码、课程名称、开课院系、课程类别
- 班次、校区、任课教师、学分、学时

**可选列**：
- 选课说明、是否线上、自定义类别

### 已选课程导入/导出Excel格式

**基础信息列**（动态适配原始课程一览表）：
- 自动复制原始Excel的列名和顺序
- 支持多种列名变体的智能识别

**排课扩展列**：
- 自定义类别：用户设置的学分类别
- 是否线上：线上/线下状态标识
- 类别锁定：类别是否可修改标志

**时间段列**（每组3列，最多5组）：
- 星期几X：1-7（周一到周日）
- 节次X：格式"开始-结束"（如：1-2, 3-4）
- 周次X：支持多种格式（如：1-10, 1,3,5,7）

**格式特点**：
- 完全兼容原始课程一览表格式
- 智能处理NaN值和空值
- 精确的错误定位和提示
- 支持复杂的时间安排表达
