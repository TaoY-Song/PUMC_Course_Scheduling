# Scripts 工具脚本目录

## 📋 目录说明

本目录包含排课系统的各种工具脚本和测试脚本，用于系统维护、功能测试和数据处理。

## 📁 脚本列表

### 1. course_supplement_test.py
**课程补充测试脚本**

#### 功能描述
- 自动尝试将课程一览表中缺失的课程添加到排课结果中
- 使用穷举法逐个尝试添加课程
- 进行完整的约束检查（时间冲突、校区冲突等）
- 生成详细的测试报告和统计信息

#### 主要特性
- ✅ **准确的线上课程识别**：优先使用Excel"是否线上"列数据
- ✅ **完整的校区冲突检查**：考虑周次重叠的时段模式检查
- ✅ **详细的时间信息解析**：从Excel文件解析多个时间段
- ✅ **智能的约束检查**：线上课程跳过校区冲突检查
- ✅ **全面的统计报告**：分类统计成功率和失败原因

#### 使用方法
```bash
cd /path/to/PUMC_Course_Scheduling
python scripts/course_supplement_test.py
```

#### 输入文件
- **课程一览表**：`生医工备选课表.xlsx`
- **排课结果**：`排课结果.xlsx`

#### 输出文件
- **补充后排课结果**：`补充后排课结果.xlsx`
- **控制台报告**：详细的执行过程和统计信息

#### 配置说明
脚本内置以下配置：
- **校区冲突模式**：时段模式（PERIOD）
- **约束检查**：时间冲突 + 校区冲突
- **课程优先级**：线上课程优先处理
